# Citation Formatting Rules (v1)

Every response generated by the Resolver MUST conclude with formal citation tags referencing retrieved evidence and policy rules.

## Syntax Requirements
- The citation block must be at the very end of the response text.
- Wrap citations in square brackets: `[Citations: ...]`
- Thread citations must use the syntax: `Thread #<THREAD_ID>` (e.g., `Thread #199189`)
- Policy citations must use the syntax: `Policy <POLICY_ID>` (e.g., `Policy POL_BILL_01` or `Policy ART_101`)
- Separate multiple citations with commas: `[Citations: Thread #199189, Policy POL_BILL_01]`
- If no specific thread applies, output the matched policy article: [Citations: Policy ART_BUG_01]
- Never invent fabricated thread IDs or policy codes.
